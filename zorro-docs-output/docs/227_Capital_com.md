# Capital.com

# Capital.com Plugin

 **Capital.com™** is a brokerage for Forex, Shares, indices and commodities. It provides manual trading, charting and technical analysis, copy trading, and algorithmic trading. The Capital.com plugin allows to retrieve data and place trades through the Capital.com API. It was developed by D�vid Bod�.

The Capital.com plugin is not included in the Zorro distribution. Get it from Github:

*   Download and install the release build from [https://github.com/Boddav/zorro-capitalcom-plugin](https://github.com/Boddav/zorro-capitalcom-plugin). Put the DLL in your **Plugin** directory.  
    
*   Start Zorro. Make sure that you now can select **Capital.com** from the \[Account\] scrollbox.
